# 采集信号漂移幅度验证

## 1. 目的

GM-IX 实机采集时，`ofdr` 输出的 `dist` 轴与 `ps` 幅度在多帧之间明显漂移，导致：
- 平均组（`AVG/`）无法按 ICD §2.2 的 5% 轴容差成立；
- 测距绝对值不稳定。

本实验用于量化漂移幅度，并排除"AFE 自动增益"这一候选原因。

## 2. 环境与方法

| 项 | 值 |
|---|---|
| 日期 | 2026-11-06 |
| 设备 | GM-IX（QT2144），`192.168.5.20`，主机 `192.168.5.55` |
| SDK | `qt_acq.dll` 0.1.0 + `ofdr.dll`（`references` 版） |
| 采集参数 | 50 MHz / 8 ms / 1 段 / 软件触发 / 延时 1 ms |
| 每组帧数 | 20 |
| 变量 | `config/QT2144/FunctionalConfiguration.json` 的 `is_RecGain`（true / false） |

脚本：`probe.ps1`。每组采集后对每帧调用 `ofdr_process`，记录：
`dist` 末值、`ps` 最大值、`ps` 最大点距离、`ch0` 均值/标准差/最小/最大值。

配置仅在 `%TEMP%` 探针目录的副本上修改，每轮结束自动还原；`references/` 未改动。

**确定性前提已验证**：同一份 raw 连续调用 `ofdr` 5 次，结果逐位相同，说明漂移来自输入信号而非库内部随机性。

## 3. 结果

| 指标 | `is_RecGain=true`（基线） | `is_RecGain=false` | 预热 1 小时后 |
|---|---|---|---|
| `dist` 末值 relDev | **16.73%**（84.93~99.14 m） | 17.70%（84.52~99.48 m） | **16.82%**（84.63~98.87 m） |
| `dist` 末值 CV | 5.87% | 5.87% | 5.41% |
| `ps` 最大值 relDev | 249.85%（9.77M~34.18M） | 338.55%（7.84M~34.38M） | 261.57%（9.68M~34.99M） |
| `ch0` 均值 relDev | 50.80% | 52.45% | 40.20% |
| `ch0` 标准差 relDev | **226.14%**（76.1~248.0） | 229.44%（75.7~249.4） | **193.76%**（83.0~243.8） |
| `ps` 最大点位于 ~0 m | 15/20 | 16/20 | 15/20 |

原始数据：[baseline_recgain_true.csv](baseline_recgain_true.csv)、[recgain_false.csv](recgain_false.csv)、[warmed_60min.csv](warmed_60min.csv)。

## 4. 结论

1. **AFE 自动增益不是原因**：关闭 `is_RecGain` 后，`dist`、`psMax`、`ch0` 各项波动均未改善（差异在噪声范围）。
2. **输入信号幅度本身在漂移**：`ch0` 标准差在 76~248 之间跳（约 3 倍），`ps` 峰值波动 2.5~3.4 倍。这不是处理链放大，而是采集端拿到的信号就不同。
3. **距离轴漂移 17%** 由信号漂移派生（`ofdr` 依据信号反推扫频特性），不是独立故障。
4. **`ps` 峰值常落在零距（0 m）**：20 帧中 15~16 帧的最大功率点位于零距，说明近端反射/直流分量占主导，远端峰相对弱。
5. **预热不是原因**：设备开机满 1 小时后复测 20 帧，`dist`（16.82%）、`psMax`（261.57%）、`ch0Std`（193.76%）波动与刚开机时同量级，未收敛。

## 5. 对开发的影响

- 平均组（`AVG/`）在硬件稳定前**无法按现行 ICD §2.2 判据成立**；
- 测距（`dist`）绝对值不可用于精度判定，只能作相对参考；
- 这是硬件/前端问题，软件侧无法通过参数修正。

## 6. 尚未排除的方向

| 方向 | 状态 | 说明 |
|---|---|---|
| 光源/电路预热 | **已排除** | 开机 1 小时后复测 20 帧，波动无收敛 |
| 触发与扫频同步 | 已排除 | 延时 0/1/2/4/8 ms 各 5 帧，波动均 8~16%，无收敛 |
| `ofdr` 随机性 | 已排除 | 同一 raw 5 次结果逐位相同 |
| AFE 自动增益 | 已排除 | `is_RecGain` true/false 各 20 帧，波动无改善 |
| 采集前端硬件 | **待厂商确认** | 建议提交 `ch0` 幅度约 3 倍波动与 `ps` 峰值 2.5~3 倍波动的实测数据 |

## 7. 复现

```powershell
# 基线（is_RecGain=true）
powershell -ExecutionPolicy Bypass -File probe.ps1 -RecGain true -Frames 20 -OutCsv baseline.csv

# 关闭自动增益
powershell -ExecutionPolicy Bypass -File probe.ps1 -RecGain false -Frames 20 -OutCsv recgain_false.csv
```
