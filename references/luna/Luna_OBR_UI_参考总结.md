## 2. 两种产品形态的界面结构

Luna 的 4600 与 6200 不是同一套 UI，参考时要分开看。

### 2.1 OBR 4600：桌面软件，六区布局

4600 用户手册第 3 章（p.18–19）把主窗口分为 6 个功能区：

1. **System Control**：仪器控制与测试参数（中心波长、波长范围、增益、连续扫描、Scan 按钮等）。
2. **Data Processing**：空间分辨率、Integration Width；购买分布式传感选件后该区域会切换为传感参数。
3. **Display Options**：控制显示哪些 trace、在内存中移动数据、查看每条测量详情。
4. **System Status Bar**：饱和、过热等状态提示。
5. **两个 Graph 区**：上图显示时域数据，下图显示时域或频域数据；每张图顶部有参数下拉菜单，左下角有坐标轴、光标、图例、缩放按钮。
6. **Menu Bar**：文件读写、打印、参考扫描、测量与显示选项。

可直接借鉴的点：**上方参数/状态、下方主图、右上角图例**的分区方式；双图上下对照（时域/频域）也适合后续扩展到「曲线 + 频谱」双视图。我们的桌面版当前是「指标表 / 距离域」两页签，不必一次改成六区，但可以把「状态栏 + 图例」做得更接近。

### 2.2 OBR 6200：一体机触摸屏，上下分区

6200 用户手册第 4 章（p.7）描述：

- **上半区**：测量控制与信息（Measure 按钮、Port A/B 通道选择、Settings and Tools、文件操作、配置管理）。
- **下半区**：左侧 **Delay Plot**（反射幅度 vs 长度），右侧 **可选 Event Table**。
- 事件表可关闭，把显示面积让给曲线（p.13）。
- 文件与配置集中在 Settings and Tools 下：Save / Load / Export / Delete File，以及 Save / Load / Startup / Delete Configuration（p.18–26）。

这与我们一期「距离域」页的上下结构（曲线 + 事件表）最接近，差别是我们用页签把「指标表」和「距离域」分开，Luna 6200 是同一屏内左右分栏。

## 3. 曲线与光标

### 3.1 6200 的四种光标模式（p.8）

曲线右上角可切换 Cursor Type：

| 模式 | 形态 | 用途 |
| --- | --- | --- |
| None | 只显示曲线 | 纯观察 |
| Single | 一条竖线 + 积分区 | 测单个事件的 RL 与 IL |
| Vertical | 两条竖线 | 测两点间距、任意区间 IL |
| Horizontal | 两条横线 | 比较两个特征的幅度 |

细节：

- **Single**（p.9）：红色高亮区用于 RL 积分，两个灰色高亮区用于 IL 计算；RL Width、IL Width 在 Measurement Tab 中可调。
- **Vertical**（p.9–10）：两条竖线，右上角显示 RL、位置、IL；可测两事件间的长度，也可测任意距离上的 IL。
- **Horizontal**（p.11）：比较两个事件的幅度；手册特别提醒，滤波程度不同会让反射峰看起来偏小。
- **拖动反馈**：按下光标时变黑，表示可拖动；单击光标会吸附到其高亮区内最高点（p.8）。
- **手势**（p.9）：曲线内拖动平移；双指捏合缩放；先按坐标轴可约束单轴平移/缩放，轴变蓝；双击坐标轴按全数据范围自适应。

### 3.2 4600 的三种光标与图例（p.72–73）

- 默认提供三类光标：**垂直、水平、twin locked**，初始位于 X 轴 10% 与 90%；水平光标位于 Y 轴 10% 与 90%。
- 光标默认附着在 Trace A，可从下拉菜单切换到其他 trace。
- 任一光标开启时，**右上角出现图例**，给出光标精确位置、两光标间距（dX 或 dY）、各光标回损以及差分损耗。
- 用于计算回损与差分损耗的积分数据点会用对比色高亮；可关闭 `Options > Cursors > Show Integration Area`。
- Integration Width 控制积分点数；`Move cursors to peak` 可把两条竖线移到各自区域峰值。
- twin locked 光标无论拖到哪里都落在第一条 trace 的数据点上。

可借鉴的点：**图例放在图内右上角**，同时显示位置、Δ距离、RL 与差分损耗；这比我们当前的「绘图区下方读数条」更节省纵向空间。我们的双光标已经相当于 `Vertical` 模式。

## 4. 事件表

### 4.1 6200：内置 Event Table

6200 手册 p.12–14：

- 事件表显示时延域中检测到的 **Return Loss（RL）事件**与 **Insertion Loss（IL）事件**，给出 **位置、回损、插损**。
- 判定规则：
  - RL 事件：回损上升量达到 `RL Threshold (dB)`。
  - IL 事件：存在明显插损，但不同时伴随 RL 事件。
  - 插损按事件前后回损差的一半计算。
  - 同一位置若 RL 事件也满足 IL 阈值，**RL 事件优先**，只标记为 RL 事件。
- `RL Width (m)` / `IL Width (m)` 决定参与计算的区域宽度，会影响相邻峰是合并为一个事件还是分开。
- 事件表默认显示，可在 Settings and Tools 的 `Events` 视图开关中关闭/恢复。
- `Show Event Markers in Plot` 打开后，在所有事件位置画竖线。
- 交互：
  - 单击事件条目 → 在图中该位置画标记；再点一次取消。
  - 使用 Single 或 Vertical 光标时，单击条目会把最近的光标吸附到事件位置（p.14）。
  - **双击事件条目 → 曲线缩放到该事件位置**。

### 4.2 4600：基础软件与 LightPath Analysis 选件分开

4600 基础软件以光标、trace 对比为主；**事件列表属于 LightPath Analysis（LPA）选件**（第 6 章，p.77 起）。

- LPA 可对照两类标准：**golden Reference Trace** 或 **Parameter Configuration File**。
- 自动识别三类 Feature：**Peak（峰）、Drop（跌落）、Fiber（光纤段）**；功能包括自动 event mapping、RL/IL 随长度合格判定、Pass/Fail 可视化（p.77）。
- **Trace Event Listing** 字段：**Type、Return Loss、Insertion Loss、Location、Result（Pass/Fail）**（p.85）。
- 选中表格行 → 图中对应 feature 加粗高亮；光标会停在 feature 中心或接续点（p.85）。
- 失败项在 Feature Tolerance Detail 区域以红色显示；可逐项查看容差（p.85）。

对我们的意义：**「事件表」在 Luna 产品里不是统一形态**。6200 是运行中实时检测的内置表；4600 是离线/质检用的 Pass/Fail 列表，并且需要选件。我们一期更接近 6200 的实时表，不应把 4600 LPA 的 Result 列当成必需功能。

## 5. 与一期「距离域」实现的对照

| 项目 | Luna 参考 | 一期现状 | 判断/建议 |
| --- | --- | --- | --- |
| 页面布局 | 6200：上控制、下左曲线右事件表；事件表可隐藏 | Tab 分两页，距离域内 62% 曲线 + 38% 事件表 | 保持 Tab；可增加事件表显隐，兼顾曲线放大 |
| 光标 | 6200 四种模式；4600 三种 + 图例 | A/B 两条竖线，下方读数条 | 双竖线已覆盖 Vertical；Single/Horizontal 属增强 |
| 光标吸附 | 6200 单击吸附区内最高点；4600 Move cursors to peak | 无吸附 | 建议做「单击吸附到最近峰」，实现简单、收益明显 |
| 读数位置 | 6200 右上角显示 RL/位置/IL；4600 右上图例 | 绘图区下方读数条 | 可保留现有，避免压缩曲线；也可把关键值移到右上角 |
| 事件表字段 | 6200：位置、RL、IL；4600 LPA：Type、RL、IL、Location、Result | 序号、距离、回损、段插损、累积、宽度 | 我们多了段插损/累积/宽度，缺事件类型；不要照搬 Result |
| 事件类型 | RL 事件 / IL 事件，RL 优先 | 全部按同一阈值检出，无类型 | 若要加类型列，需先定义 IL 事件算法与阈值；属二期 |
| 事件判定宽度 | RL Width / IL Width 可调，影响合并 | mergeGap 固定于配置快照 | 可调会改变 `ComputeId`；建议二期用独立显示配置 |
| 事件标记 | 6200 可开关；单击条目加/取消标记 | 始终显示竖线/三角 | 建议加「显示事件标记」开关 |
| 表图联动 | 单击条目吸附光标；双击缩放定位 | 双击把光标 A 移到事件距离 | 建议改为「双击缩放」，更符合用户预期 |
| 表格显隐 | 6200 可关闭事件表 | 固定 62/38 | 建议加显隐按钮 |
| Pass/Fail | 4600 LPA 对照 golden trace | 未做，且一期范围外 | 保持不做；列入二期候选 |
| 多 trace 对比 | 4600 支持多条 trace 与参考 trace | 单帧曲线 | 二期再评估 |

## 6. 建议落地的最小改进

按「改动小、与现有架构不冲突」排序：

1. **事件表增加「类型」列**：一期可先只标「反射事件」，为后续 IL 事件留位置；不建议在没有 IL 判定算法时伪造类型。
2. **双击事件条目改为缩放定位**：当前双击只把光标 A 移到事件位置，改为同时把横轴缩放到事件附近（保留 A 光标移动也可）。
3. **单击事件条目光标吸附**：把最近的光标（A 或 B）移到事件峰位，和 6200 的行为一致。
4. **事件标记开关**：在距离域页加一个「显示事件标记」复选框，关闭后只保留曲线与光标。
5. **事件表显隐**：允许把 38% 的事件表收起，曲线占满；可作为后续布局优化。
6. **Single 光标模式**：若后续需要直接读单事件 RL/IL，可增加「单光标 + RL 积分区 + 两侧 IL 区」；一期双竖线已够用。
7. **阈值/宽度可调**：Luna 的 RL/IL Threshold、RL/IL Width 都在 UI 中可调；我们受 `MetricsConfig` 快照与历史 CSV 比对约束，建议二期单独做「显示/事件参数」，不要直接改现有配置字段。

## 7. 明确不照搬的部分

- **触摸手势**：6200 的捏合缩放、按轴约束是触摸屏交互；桌面鼠标版用滚轮/拖拽即可，不必复刻。
- **Delay 单位与坐标**：6200 称 Delay Plot，横轴是时延/长度；我们统一用「距离 (m)」，保持现有口径。
- **IL 定义**：6200 的 IL 是事件前后回损差的一半；我们的「段插损」是两峰间平直段的均值差，另有「累积插损」。两者语义不同，界面文字必须写清楚，不能直接叫 IL。
- **4600 LPA 的 Result 列**：依赖 golden trace/参数文件与容差体系，超出一期范围。
- **多 trace 与参考扫描**：4600 的 Display Options、Reference Scan 属离线分析能力，一期不做。
