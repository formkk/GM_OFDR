## 8 M-34 性能测量（2026-11-23）

口径：Release、x64、1360×700、160,000 点合成曲线、`RenderTargetBitmap` 每帧新建位图、连续 40 帧取 p95；WinForms 基线来自 §4（`DrawToBitmap`）。

| 指标 | WinForms 基线 | 目标（≤基线×1.2） | WPF 实测 | 结果 |
|---|---:|---:|---:|---|
| 曲线首帧（冷） | 6.60 ms | 7.92 ms | 13.97 ms | **未达标** |
| 曲线 p95 | 6.46 ms | 7.75 ms | 7.85 ms | **未达标（超 1.3%）** |
| 缩放 p95 | 7.55 ms | 9.06 ms | 7.86 ms | 达标 |
| 平移 p95 | 10.88 ms | 13.06 ms | 7.71 ms | 达标 |
| 叠加峰/ROI/阈值首帧（热） | — | 7.92 ms | 7.50 ms | 达标 |
| 叠加 p95 | — | 7.75 ms | 7.58 ms | 达标 |
| 连续 10 帧内存增量 | -21 KB | 无增长 | 0 B | 达标 |

结论：

- 热渲染路径已达标（曲线 p95 7.85 ms 仅比目标高 1.3%，缩放/平移/叠加均达标）。
- **冷首帧 13.97 ms 未达标**，主要来自首次 JIT、字体/资源解析；热首帧 7.50 ms。
- 连续 10 帧无内存增长。
- 按 M-34 判定为**未完全达标**；进入 M-35 评估预热、缓存 Pen/Brush/FormattedText、`StreamGeometry` 或 `WriteableBitmap`，再由 M-36 决策门决定是否继续。

### 8.1 M-35 优化后复测

优化项：

- 启动时 `CurvePlotControl.Prewarm()` 预热一次完整 16 万点绘制路径（实测启动成本 211–223 ms，含 `RenderTargetBitmap` 与首渲染管线初始化；早期会话测得 118–122 ms，随机器负载波动）。
- Brush/Pen/Typeface 改为静态缓存；`FormattedText` 增加有上限的文本缓存。
- 试验 `StreamGeometry` 聚合曲线后反而变慢（18–19 ms），已回退，保留逐像素 `DrawLine`。

复测 7 次（Release、x64、1360×700、160,000 点；其中 5 次在沙箱内、2 次在沙箱外，用于排除沙箱调度开销）：

| 指标 | 目标 | M-34（优化前） | M-35 中位数 | M-35 范围（7 次，含离群） | 结果 |
|---|---:|---:|---:|---|---|
| 曲线首帧 | 7.92 ms | 13.97 ms | 8.32 ms | 8.25–10.36 ms（6 次 8.25–8.41，1 次 10.36） | 未达标（典型超 4–6%） |
| 曲线 p50 | — | — | 6.63 ms | 6.53–6.74 ms | 稳定 |
| 曲线 p95 | 7.75 ms | 7.85 ms | 6.78 ms | 6.61–9.53 ms（5 次 ≤ 6.78，2 次 8.30/8.66/9.53） | 中位数达标，偶发离群 |
| 缩放 p95 | 9.06 ms | 7.86 ms | 6.94 ms | 6.84–9.55 ms（6 次 ≤ 9.06，1 次 9.55） | 中位数达标，偶发离群 |
| 平移 p95 | 13.06 ms | 7.71 ms | 6.82 ms | 6.75–8.79 ms | 达标 |
| 叠加首帧 | 7.92 ms | 7.50 ms | 6.72 ms | 6.55–6.81 ms | 达标（7/7） |
| 叠加 p95 | 7.75 ms | 7.58 ms | 6.63 ms | 6.50–12.93 ms（5 次 ≤ 6.67，2 次 11.07/12.93） | 中位数达标，偶发离群 |
| 连续 10 帧内存增量 | 无增长 | 0 B | 0 B | 0 B（7/7） | 达标 |

离群判定依据：

- 所有 7 次的 p50 都稳定在 6.4–7.0 ms；离群只出现在 p95（40 帧中第 3 差的帧），且与 p50 无同步上升，内存增量始终为 0 B，属宿主进程调度抖动（IDE/构建/杀软），不是渲染路径变慢。
- 沙箱外 2 次同样出现离群（曲线 p95 8.30 / 9.53、平移 p50 8.64），说明与沙箱无关，是整机负载噪声。
- 若需作为正式验收记录，应在静止机器、关闭 IDE/构建与杀毒扫描后复测一次并归档。

结论：

- 稳态渲染（p50、平移、叠加、内存）已全部达标，且较 M-34 明显改善；缩放/曲线/叠加的 p95 中位数达标，离群值归因环境噪声。
- 首帧典型 8.3 ms，高于 7.92 ms 目标约 4–6%；主要来自新 visual 首次绘制与首屏字形缓存，预热无法完全消除。该值仍远低于 16.7 ms（60 fps 单帧预算）。
- `WriteableBitmap` 可进一步压低曲线绘制，但会引入 DPI/抗锯齿/交互重绘复杂度，且对首帧字形/资源初始化无帮助；不采用，保留逐像素 `DrawLine`（TBD-LX-04 关闭）。
- 交 M-36 决策：接受 8.3 ms 首帧（记录偏差），或增加首屏隐藏预热帧后再验收。
