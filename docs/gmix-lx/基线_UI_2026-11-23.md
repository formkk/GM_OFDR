## 1 环境与方法

| 项 | 内容 |
|---|---|
| 操作系统 | Windows x64 |
| 运行时 | .NET SDK 10.0.404，WindowsDesktop 10.0.15 |
| 构建 | Release，x64 |
| 采样点数 | 160,000（合成曲线，模拟映讯 GM-IX 单帧） |
| 曲线窗口 | 1360 × 700 |
| 截图方式 | 离屏 WinForms `Form.DrawToBitmap`（不依赖显示器可见性） |
| 性能方式 | Release 下对完整窗口执行 20 次 `DrawToBitmap`，取 p50/p95；缩放/平移各 8 次 |
| 内存方式 | `GC.GetTotalMemory(true)` 在连续 10 次绘制前后对比 |

说明：这是**离屏渲染基线**，用于 WPF 迁移的同比参照，不等同于真实显示器上的肉眼帧率；绝对数值会随机器与 DPI 变化，比较时应使用同一方法与同一合成数据。

## 3 性能基线

原始数据见 [perf.txt](../assets/gmix-lx/baseline/perf.txt)。

| 指标 | 实测值 | WPF 目标（基线×1.2，且不超过上限） |
|---|---:|---:|
| 首帧耗时 | 6.60 ms | ≤ 7.92 ms |
| 连续渲染 p50 | 6.13 ms | — |
| 连续渲染 p95 | 6.46 ms | ≤ 7.75 ms（且 ≤ 33 ms） |
| 缩放 p95 | 7.55 ms | ≤ 9.06 ms（且 ≤ 33 ms） |
| 平移 p95 | 10.88 ms | ≤ 13.06 ms（且 ≤ 33 ms） |
| 连续 10 帧内存增量 | -21,072 B | 无持续增长 |

结论：当前 WinForms 曲线控件在 16 万点下渲染开销约 6–11 ms/帧，远低于 33 ms 交互预算。WPF 版按 ADR §5.4 的同比口径验收即可。

## 4 复现说明

本次使用临时离屏基座（`.tmp/GmixLx.Baseline`，不入库）完成：

1. 反射创建 `GmixLx.App.MainForm` 与 `GmixLx.App.CurveForm`；
2. 用 160,000 点合成曲线构造 `MetricTableRow`；
3. 离屏 `Show()` 后 `DrawToBitmap` 保存 PNG；
4. 对曲线窗口重复绘制并调用私有 `OnWheel` / `OnMouseDown` / `OnMouseMove` 记录缩放/平移耗时。

如需长期复现，可在阶段 3 的 WPF 曲线原型中复用同一合成数据与同一测量口径。

### 6.1 DPI 检查（M-24）

| 渲染 DPI | 文件 | 说明 |

| 96 | [dpi-96.png](../assets/gmix-lx/baseline/dpi/dpi-96.png) | 1360×620 |

- 说明：本次未自动切换操作系统 100%/200% 缩放；已用等价 DPI 渲染验证布局，现场切换仍建议复核一次。
