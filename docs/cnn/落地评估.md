# 低频 PSD 指纹落地评估 v0.1

> 范围：只用 50 MHz / 8 ms 数据；特征为「每段去电平 + 低频 PSD（20 mm 物理网格，6 个波长带）」。
> 结论：**特征路线可行，但当前只能证明"段级可区分且对网格漂移较稳"，还不能证明"跨光纤身份识别"**。落地前必须补多光纤、多会话数据。

## 1 实测能力

样本：20 帧连续采集 + 2 次独立采集 = 22 次 × 4 段。同段跨采集为正样本，异段为负样本。

| 指标 | 结果 |
|---|---|
| AUC | 0.976 |
| EER | 7.4% |
| 同段距离 p50 / p95 | 1.43 / 2.59 |
| 异段距离 p5 / p50 | 2.30 / 3.52 |
| Δstep > 30 µm 子集 AUC | 0.961 |
| 4 段识别（留一采集） | 0.925 |
| 特征提取耗时 | 0.73 ms / 次采集（4 段） |

多帧平均（连续帧分块，dB 域平均后重算 PSD）：

| 平均帧数 | 组数 | AUC | EER | 4 段识别 |
|---|---|---|---|---|
| 1 | 20 | 0.974 | 7.9% | 0.925 |
| 2 | 10 | 0.983 | 6.7% | 0.900 |
| 4 | 5 | 0.990 | 5.8% | 0.900 |
| 5 | 4 | 0.990 | 4.2% | 0.938 |

扰动（全部 22 次采集）：

| 扰动 | AUC | EER |
|---|---|---|
| 无 | 0.976 | 7.4% |
| 增益 +3 dB | 0.976 | 7.4% |
| 倾斜 4 dB | 0.951 | 10.5% |
| 倾斜 8 dB | 0.949 | 10.6% |
| 噪声 σ=0.3 dB | 0.977 | 7.6% |

增益被每段去电平完全消除；倾斜会侵蚀低频带能量，AUC 降到 0.95；噪声基本无影响。

阈值取舍（段级距离，越小越同段）：

| 阈值 | FAR | FRR | TAR |
|---|---|---|---|
| 2.30 | 5.1% | 10.5% | 89.5% |
| 2.40 | 7.1% | 7.7% | 92.3% |
| 2.50 | 10.3% | 6.3% | 93.7% |
| 2.60 | 14.3% | 4.9% | 95.1% |

当前建议：阈值 2.4，灰区 2.3~2.6 判「不确定，需复测」，不要强行出结论。

## 2 落地架构

```
采集(50MHz/8ms, 固定扫频)
  → 5 峰分段（保护带 0.1 m）
  → 每段相对坐标（峰锚定）
  → 去电平（零均值单位方差）
  → 10~20 mm 块平均 → 低频 PSD（6 维对数能量）
  → 模板库（每段 6 维 + 元数据）
  → 段级距离 → 多段融合 → 判定/灰区
```

- **模板**：6 维浮点向量即可，不需要 128 bit 码。维度太低，二值化只会损失信息；"指纹码"仅在需要固定长度标识时再考虑。
- **多帧**：落地建议 4~5 帧平均。8 ms/帧、设备约 19 帧/秒，4 帧约 0.2 s，延迟可接受；EER 从 7.4% 降到 5.8%。
- **多段融合**：一次采集取 4 段距离的均值（比取最大稳），低于阈值才判同链路；单段异常（峰缺失/SNR 低）时降级为 3 段并标注。
- **元数据**：每段记录长度、末端峰位、峰值、dist 步距、采集时间、DeviceId。步距 > 阈值（如相邻采集 Δstep ≥ 0.01 mm）时标注「网格漂移，结果降级」。

## 3 判定流程

1. 采集 4~5 帧，检查 5 峰完整、SNR ≥ 20 dB、dist 步距与注册时差 < 0.01 mm；
2. 每帧每段算 6 维 PSD，按帧做功率域平均（不要 dB 算术平均）；
3. 与注册模板算欧氏距离，4 段取均值；
4. 距离 < 2.3 → 同链路；2.3~2.6 → 灰区，提示复测/人工确认；> 2.6 → 不同链路；
5. 任一段峰缺失或 SNR 不足 → 不判定，走错误上报。

## 4 指标口径与验收

必须同时报告：

- **段级**：AUC、EER、同段/异段距离分布；
- **链路级**：同光纤 rank-1、FAR@FRR=1%、跨天/跨插拔复现率；
- **分层**：按 dist 步距差（<3 µm / 3–10 µm / 10–30 µm / >30 µm）分组；
- **多帧**：单帧 vs 4 帧平均分别报告；
- **扰动**：增益、倾斜、距离平移、温度、弯曲。

当前结果只能填「段级 + 同 DUT」，链路级和开放集为空。

## 5 数据缺口

| 缺口 | 影响 | 补采要求 |
|---|---|---|
| 只有 4 段、单一 DUT | 无法估计跨光纤误识率 | ≥10 根**同型号同长度**光纤做负样本 |
| 只有一次连续会话 + 2 次独立采集 | 无法估计跨天/重插拔 | 每根 ≥5 次重插拔、≥3 天复测 |
| 未确认分光器拓扑 | 4 段是否同一链路存疑 | 现场确认 5 峰对应关系 |
| 20 mm 网格参数在小样本上选出 | 有过拟合风险（15/25 mm 仅 0.914/0.894） | 在独立数据上复核，固定参数后再评估 |
| dist 步距逐次变化 | 跨采集相似度下降 | 固定扫频，或记录步距并分层 |

## 6 与产品线集成

- **P0（现在）**：保持 `CNN/` 离线工具，输入 GM-IX 导出的 `dist/ps_db` 或 raw + ofdr，输出评估报告；不改产品线。
- **P1**：在 GM-IX 内加只读的「链路指纹」分析模块，复用现有 `Gmix.Data` 的标定/存储，不新增契约字段、不改 UI 主流程。
- **P2**：只有跨光纤数据通过验收后，才考虑模板库、采集适配器（LGA50）和现场流程。

## 7 风险登记

1. **20 mm 过拟合**：当前 AUC 0.976 是在小样本上挑的网格；15/25 mm 明显更低。需要在独立数据上冻结参数后复测。
2. **段间差异 ≠ 光纤唯一性**：4 段的长度/衰减/端面位置不同，模型可能利用这些差异。必须用同长度多光纤排除。
3. **指纹可模拟**：反射曲线可以被复制，指纹只能做相似性核对，不能当防伪或加密认证。
4. **网格漂移**：Δstep > 30 µm 时 AUC 仍有 0.961，但更极端的漂移未测；现场必须监控步距。
5. **温度/弯曲/老化**：完全未覆盖，可能超过当前阈值裕量。

## 8 分阶段路线

| 阶段 | 内容 | 决策门 |
|---|---|---|
| P0 离线基线 | 冻结特征口径、阈值、指标表；在现有 22 次采集上复现 | 报告可复现，脚本可重跑 |
| P1 数据补齐 | ≥10 根同长度光纤 × 5 次重插拔 × 3 天，每会话 ≥100 帧 | 同长度多光纤 EER ≤ 5%，跨会话 rank-1 ≥ 95% |
| P2 工程化 | GM-IX 只读模块、模板库、灰区策略、步距/SNR 监控 | 现场 3 天复测 EER ≤ 2%，误拒可接受 |
| P3 推广 | 接入 LGA50 或其它设备线 | 跨设备归一化后仍满足验收 |

P1 的决策门是硬门槛：**没有同长度多光纤数据，不进入工程化**。
