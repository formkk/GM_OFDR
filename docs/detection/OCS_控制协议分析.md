# OCS 控制协议分析（1×8 / 8×8）

> **来源**：`references/ocs/控制协议1X8(2).docx`、`references/ocs/控制协议8X8(2).docx`（厂商原始文档）。
> **状态**：文档提取 + **2026-11-11 实机核对**（1×8 = COM4 @ 9600，8×8 = COM3 @ 115200）。实测数据、错误码与时序见 [OCS 协议实测报告](OCS_协议实测报告_2026-11-11.md)；本文保留协议结构，**与实测冲突时以实测为准**。
> **关联**：本文部分关闭 `TBD-D02`（OCS 控制接口与命令集）；`TBD-O01~O10` 实测状态见 §8；`TBD-D04`（切换稳定时间）仍需光学仪器。

## 1. 结论摘要

- 两型 OCS 均为 **RS232、ASCII 字符帧**，帧格式为 `<` + 命令 + `>`。
- **波特率按设备不同（2026-11-11 实测）**：1×8 为 **9600 8N1**；8×8 为 **115200 8N1**。厂商文档把两型都写成 9600，与 8×8 实物不符。
- **1×8**：单输入 `COM`，8 选 1；命令集小，只有单路设置与当前通道查询。
- **8×8**：8×8 矩阵；支持单路设置、整矩阵一次性设置、单路查询与全量查询。
- 8×8 整矩阵设置有一条硬约束：**非 0 输出不可重复**，否则设备返回 `<ER_SetValue>`；**单路设置不校验唯一性**（实测），上位机必须自行校验。
- 两型共有命令：`<IDN?>`、`<SN?>`、`<RST>`、`<SETSW...>`、`<QURSW...>`。
- 帧以 `>` 为执行边界：**缺 `>` 的帧会挂起直到补齐**；结束符（CR/LF/CRLF）可选；无回显；命令必须串行。
- 仍未关闭：切换光功率稳定时间、复位后状态（需显式 `<RST>`）、串口线序、光学指标、1×8↔8×8 光口物理映射。

## 2. 物理层与帧格式

| 项 | 文档内容 | 状态 |
|---|---|---|
| 接口 | RS232 | 文档明确 + 实机 |
| 波特率 | 1×8：9600；8×8：**115200** | 实机实测（文档写两型均 9600，8×8 不符） |
| 数据位 | 8 | 文档明确 + 实机 |
| 停止位 | 1 | 文档明确 + 实机 |
| 校验 | 无（8N1） | 实机确认；8E1/8O1 帧损坏 |
| 编码 | 标准 ASCII | 文档明确 |
| 帧格式 | `<` + 命令 + `>` | 文档明确 + 实机；缺 `>` 时挂起 |
| 流控 | 未说明 | **实测必须 `Handshake=None`**；RTS/CTS 与 XON/XOFF 均写超时 |
| CR/LF | 未说明 | 实测 none/CR/LF/CRLF 均可；无回显 |
| 回包格式 | `<...>` | 文档明确；实测无回显 |
| 通用错误 | `<ERROR>` | 文档明确 + 实机 |
| 8×8 整矩阵冲突 | `<ER_SetValue>` | 文档明确 + 实机 |
| 应答时延 | 未说明 | 实测 8×8：查询 1~6 ms、单路 22 ms、整矩阵 148 ms；1×8：17~67 ms（p99） |

> 实现提示：串口读取不要依赖 `ReadLine()`；应按 `<...>` 定界读取，并设置最大长度与超时。**不要发送半帧**：设备没有帧内超时，半帧会一直占用解析器，直到补上 `>` 才执行。

## 4. 1×8 命令集

| 命令 | 成功返回 | 语义 |
|---|---|---|
| `<IDN?>` | `<GK,GK-OSW-1X8-SM-1315-FU-R-01,2026-08-03,VERSION1.0>` | 查询设备信息 |
| `<SN?>` | `<26080301>` | 查询设备编号 |
| `<RST>` | `<OK>` | 设备复位 |
| `<SETSW1-yy>` | `<1-yy>` | 设置 `COM` → `CHyy`；`yy=0` 断开，`1~8` 对应 CH1~CH8 |
| `<QURSW?>` | `<SW1-yy>` | 查询当前通道 |

示例：

```text
发送：<SETSW1-03>
返回：<1-03>          # COM → CH3
发送：<QURSW?>
返回：<SW1-03>
```

说明：

- 输入通道 `x` 固定为 `1`（COM），文档没有提供其他输入。
- 同一时刻只有一个输出有效；`yy=0` 表示断开。
- 文档未提供逐通道查询，也没有整矩阵设置命令。
- 断开命令返回实测为 `<1-00>`，回读 `<SW1-00>`（TBD-O02 已关闭）。

## 5. 8×8 命令集

| 命令 | 成功返回 | 语义 |
|---|---|---|
| `<IDN?>` | `<GK,GK-OSW-8X8-SM-1315-FU-R-01,2026-08-03,VERSION1.0>` | 查询设备信息 |
| `<SN?>` | `<26080302>` | 查询设备编号 |
| `<RST>` | `<OK>` | 设备复位 |
| `<SETSWx-yy>` | `<x-yy>` | 设置 `INx` → `OUTyy`；`x=1~8`，`yy=0~8` |
| `<SETSWabcdefgh>` | `<OK>` | 一次性设置 8 路；`a~h` 对应 `IN1~IN8` 的输出，取值 `0~8` |
| `<QURSWx?>` | `<SWx-yy>` | 查询第 `x` 路当前输出 |
| `<QURSW?>` | `<SW0a_0b_0c_0d_0e_0f_0g_0h>` | 查询全部 8 路 |
| 错误 | `<ERROR>` / `<ER_SetValue>` | 非法命令 / 整矩阵设置冲突 |

### 5.1 单路设置

```text
发送：<SETSW1-02>
返回：<1-02>          # IN1 → OUT2
发送：<QURSW4?>
返回：<SW4-02>        # IN4 → OUT2
```

### 5.2 整矩阵设置

`<SETSWabcdefgh>` 中：

- `a` 对应 `IN1` 的输出，`b` 对应 `IN2`，依此类推，`h` 对应 `IN8`。
- 每个取值为 `0~8`；`0` 表示该路断开。
- 非 0 值不可重复，否则返回 `<ER_SetValue>`。

示例：

```text
发送：<SETSW15632487>
返回：<OK>
含义：IN1→OUT1, IN2→OUT5, IN3→OUT6, IN4→OUT3,
      IN5→OUT2, IN6→OUT4, IN7→OUT8, IN8→OUT7

发送：<SETSW23340056>
返回：<ER_SetValue>    # 输出 3 重复（IN2、IN3 都指向 OUT3）
```

实测补充（2026-11-11）：

- 整矩阵重复输出确认返回 `<ER_SetValue>`，且**不改变**原矩阵。
- 整矩阵含越界值（如 `<SETSW90000000>`）返回 `<ERROR>`；含 0 的合法矩阵返回 `<OK>` 并回读生效。
- **单路命令不校验唯一性**：`<SETSW2-01>` 在 IN1 已指向 OUT1 时仍返回 `<2-01>`，回读为 `<SW00_01_03_04_05_06_07_08>`。上位机必须在发送前自行校验。

### 5.3 全量查询

返回格式为 `SW` + 8 组两位数字，组间用 `_` 分隔：

```text
<SW0a_0b_0c_0d_0e_0f_0g_0h>
```

示例：

```text
<SW03_00_01_02_04_00_06_05>
```

含义：`IN1→OUT3`、`IN2` 断开、`IN3→OUT1`、`IN4→OUT2`、`IN5→OUT4`、`IN6` 断开、`IN7→OUT6`、`IN8→OUT5`。

## 6. 1×8 与 8×8 差异

| 维度 | 1×8 | 8×8 |
|---|---|---|
| 拓扑 | 单输入 COM，8 选 1 | 8 输入 × 8 输出矩阵 |
| 输入通道 | 固定 `x=1` | `x=1~8` |
| 输出通道 | `yy=0~8` | `yy=0~8` |
| 单路设置 | `<SETSW1-yy>` | `<SETSWx-yy>` |
| 整矩阵设置 | 不支持 | `<SETSWabcdefgh>` |
| 单路查询 | 不支持 | `<QURSWx?>` |
| 全量查询 | `<QURSW?>` → `<SW1-yy>` | `<QURSW?>` → `<SW0a_..._0h>` |
| 输出唯一性 | 天然唯一（单输入） | 整矩阵命令强制非 0 输出唯一；**单路命令实测不强制**（TBD-O04 已关闭），两输入可指向同一输出 |
| 错误码 | `<ERROR>` | `<ERROR>`、`<ER_SetValue>` |

## 7. 上位机实现约束

1. **串口参数（实测强制）**：1×8 = 9600 8N1，8×8 = 115200 8N1；`Handshake = None`（启用流控会写超时）；DTR/RTS 可保持默认，不影响通信。
2. **命令串行化**：一次只发一条命令，收到完整回包后再发下一条。实测连续发送或流水线时，第二条命令返回 `<ERROR>`；不要并发，也不要在未收到回包时重发。
3. **参数校验在发送前完成**：
   - 1×8：`x` 必须为 `1`，`yy` 为 `0~8`。
   - 8×8：`x` 为 `1~8`，`yy` 为 `0~8`。
   - **单路与整矩阵都要自行校验非 0 输出唯一**：设备只在整矩阵命令上强制唯一，单路命令不强制。
4. **回包解析按定界符且严格**：读取到 `>` 结束并设置最大长度；只接受 `<...>` 且不含 `?`；实测不接受小写、括号内空格、单位数输出（`<SETSW1-1>`）、超长参数。
5. **设置后回读**：通道切换后用 `QURSW` / `QURSWx?` 回读确认，再触发 OFDR 扫描；回读不一致按设备错误处理。
6. **超时与重试（按实测 p99 × 3）**：默认 300 ms；8×8 整矩阵 500 ms。重试最多 2 次，退避 100 ms / 300 ms；持续失败按设备/传输错误上报。
7. **错误分类**：
   - 传输错误（串口打不开、写失败、读超时）；
   - 协议错误（回包不以 `<` 开头、不以 `>` 结尾、含 `?`、长度异常）；
   - 设备错误（`<ERROR>`、`<ER_SetValue>`）。
   三类错误映射为不同 UI 消息，禁止静默吞掉。
8. **状态机**：启动先查询当前状态，不默认执行 `<RST>`；复位会改变光路，必须由明确操作触发。
9. **日志**：记录原始 TX/RX（ASCII 与十六进制）、时间戳、命令序号、耗时；便于复现时序问题。

## 9. 所缺资料能否通过测试取得

结论：**协议行为与时序大部分可以通过测试取得；光学指标需要校准设备；寿命、内部设计与固件差异只能由厂商提供。**

| 类别 | 能否测试取得 | 说明 |
|---|---|---|
| 命令回包、超时、重试、幂等、CR/LF、回显 | **可以** | 串口抓包 + 重复命令统计即可 |
| 切换稳定时间、上电/复位状态 | **可以** | 需要光功率计或光电探测器 + 示波器；仅靠串口无法测 |
| 单路命令的输出唯一性 | **可以** | 构造冲突路径并回读 |
| 错误码全集 | **可以（有限）** | 只能覆盖可构造的非法输入；未公开错误码可能遗漏 |
| 串口引脚/线序 | **可以** | 万用表通断；但建议厂商确认，避免接错 |
| 插入损耗、回波损耗、串扰、波长范围 | **部分可以** | 需要校准过的光源、功率计、ORL；绝对精度依赖校准 |
| 1×8 与 8×8 级联映射 | **可以** | 逐路切换 + OFDR 峰值/光功率验证 |
| 切换寿命、MTBF、内部光学设计 | **不可以** | 只能由厂商提供或做加速寿命试验（成本高） |
| 固件版本差异、未公开命令 | **不可以** | 需厂商文档或固件说明 |

### 9.1 建议的测试顺序

1. **串口基线**：USB-RS232 + 串口监听，确认波特率/8N1、帧格式、是否有回显/CRLF。**已完成（2026-11-11）**：1×8 9600、8×8 115200。
2. **命令矩阵**：`IDN?`、`SN?`、`QURSW?`、合法/非法 `SETSW`，每类 N=100，统计 p50/p95/p99/max。**已完成**。
3. **状态与约束**：逐路设置并回读；测试 `0` 断开、越界、重复输出、复位、断电重启。**部分完成**：断开、越界、重复输出已测；复位与断电重启未测。
4. **切换时间**：光路接光功率计或光电探测器，记录“命令发出 → 光功率稳定在容差内”的时间；1×8 与 8×8 分开测，各 100 次。**未完成**（需光学仪器）。
5. **级联映射**：1×8 COM 接 8×8 输入，逐路打通，记录 64 条路径的 IL 与 OFDR 峰值位置。**未完成**（协议侧已验证 64 路可设置）。
6. **错误码扫描**：缺 `>`、多余字符、大小写、空格、未知命令、越界参数；记录回包或超时。**已完成**：统一 `<ERROR>` / `<ER_SetValue>`；缺 `>` 会挂起等待补齐。
7. **长稳**：1k/10k 次连续切换，统计错误、超时、回读不一致。**部分完成**：1×8 1000 次 0 错误；8×8 与 10k 次未做。
8. **光学指标**：校准功率计测 IL/RL，宽带源 + 功率计测串扰；或直接向厂商索取规格书。**未完成**。
