# 检测系统上位机（OCS + OFDR）

> **定位**：为 OCS 光开关与 OFDR 设备组成的检测系统开发上位机软件；它是 LGA50 自研上位机的后续版本（继承链 GM-IX → LGA50 → 检测系统）。
> **状态**：目录骨架（2026-11-11），SRS/SDD 待建。
> **交付边界**：交付物是上位机软件；硬件（光路、开关、采集板）是外部依赖与约束，不是本目录的交付内容。

## 1. 系统边界

| 项 | 内容 |
|---|---|
| 交付 | 上位机软件：通道编排、设备接入、指标计算、接线核验、结果与历史 |
| 外部 | OCS 光开关、OFDR 设备、被测光纤阵列 |
| 光路 | OFDR DUT 光口 → OCS IN → OUT×N → 被测光纤阵列 |
| 控制 | 上位机 → OFDR：扫描触发、曲线回传；上位机 → OCS：通道切换 |
| 继承 | L1 帧契约、L2 记录/处理契约、GM-IX 组存储与指标计算 |

## 2. 检测流程（待评审）

1. OCS 切到通道 i，等待切换稳定
2. 触发 OFDR 扫描，接收该通道距离域曲线
3. 计算峰 / 事件 / IL / RL
4. 与意图表或基线比对，给出判定
5. 循环至全部通道，汇总批次结果

> 时序参数（切换稳定时间、扫描超时、重试策略）尚未实测，登记为 TBD-D04。
