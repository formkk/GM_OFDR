# 检测系统上位机（OCS + OFDR）

> **定位**：为 OCS 光开关与 OFDR 设备组成的检测系统开发上位机软件；它是 LGA50 自研上位机的后续版本（继承链 GM-IX → LGA50 → 检测系统）。
> **状态**：SRS v0.4 评审稿；SDD 待建（2026-11-11）。
> **交付边界**：交付物是上位机软件；硬件（光路、开关、采集板）是外部依赖与约束，不是本目录的交付内容。

## 1. 系统边界

| 项 | 内容 |
|---|---|
| 交付 | 上位机软件：通道编排、设备接入、指标计算、测量记录、结果与历史 |
| 外部 | OCS 光开关、OFDR 设备、被测光纤阵列 |
| 光路 | OFDR DUT 光口 → OCS IN → OUT×N → 被测光纤阵列 |
| 控制 | 上位机 → OFDR：扫描触发、曲线回传；上位机 → OCS：通道切换 |
| 继承 | L1 帧契约、L2 记录/处理契约、GM-IX 组存储与指标计算 |

## 2. 检测流程（待评审）

1. OCS 切到通道 i，等待切换稳定
2. 触发 OFDR 扫描，接收该通道距离域曲线
3. 计算峰 / 事件 / IL / RL
4. 与意图表或基线比对，记录差异与关注提示（不做自动合格判定）
5. 循环至全部通道，汇总批次结果

> 时序参数（切换稳定时间、扫描超时、重试策略）尚未实测，登记为 TBD-D04。

## 4. 已知事实

- 光路拓扑：OFDR → OCS（1×8 前级路由 + 8×8 DUT）→ 被测阵列；来源为既有工程骨架与文档地图登记。
- 数据组织：一次检测 = 一个批次目录（`DETECTION_DATA/BATCH-...`）；一条路径 = 一个 L2 组；一条路径的 N 次扫描 = 组内 `Rxxx`，N>1 生成 `AVG/`。详见 [SRS v0.4 §6.6](SRS_检测平台_v0.4.md)。
- OCS 厂商协议文档：`references/ocs/控制协议1X8(2).docx`、`控制协议8X8(2).docx`。
- OCS 协议分析（文档提取，未实机核对）：[`OCS_控制协议分析.md`](OCS_控制协议分析.md)。
- OCS 实物照片：`docs/assets/ocs/`。
- 代码骨架（占位）：`products/gmix/src/Gmix.OcsVerify`（核验域纯逻辑）、`Gmix.OcsCheck`（编排进程）、`Gmix.OcsCheck.App`（UI，不引用 Vendor）。
- 夹具目录：`tests/fixtures/ocs/`。
- 可继承契约：[L1 统一数据契约](../contracts/统一数据契约_v0.7.md)、[L2 GM-IX 数据与处理规范](../contracts/GM-IX_数据与处理规范_v1.0.md)。
