## 1. 引言

### 1.1 目的

定义 GM-IX 上位机的功能、界面、数据与非功能需求，作为开发、测试与验收的基线。

### 1.2 系统边界

| 在范围内 | 不在范围内 |
|---|---|
| 设备连接、采集控制、单次/重复/循环测量 | 采集板固件、FPGA 逻辑、光学链路设计 |
| 原始字节到物理量的转换、OFDR 解算与事件检测的编排 | 厂商 DLL 内部算法复刻（黑盒，见 CON-01） |
| 总 IL/RL、精度、分析区间统计 | 云端、MES、多工位部署 |
| 距离域曲线、指标表、事件表 | 移动端、Web 端 |
| 校准参数管理、版本化、失效规则 | 标定件本身的计量溯源 |
| 组目录持久化、历史检索、导出 | 数据库服务（仅索引与路径） |
| 错误分类与可读上报 | 厂商软件 UI 的逐像素复刻 |

### 1.3 术语与单位

| 术语 | 定义 |
|---|---|
| dB_rel | detect 原始输出的相对电平 `20log10(ps)`，g50 实测基线 +98~+103、峰 +120~+147（正值） |
| RL | 回波损耗，原始比值口径 `10log10(P_refl/P_inc)`，不取倒数（规范 §0.3 #12）；未标定为正刻度，标定后为负值 |
| IL | 插入损耗；事件级 `ilDb = 后段 − 前段`（负值），UI 用 `stepLossDb = -ilDb`（正损耗） |
| `rlOffsetK` | 绝对回损的加性偏移（≈ -192），把 dB_rel 换算到负刻度 |
| 显示口径 | UI 呈现的数值与符号规则，只存于 `view.json` 与界面，不写回数据字段（§6） |
| 分析区间 | `analysisRange.startM/endM` + `guardM`（默认 0.1 m） |
| 组 / 平均 | `<groupId>/R001..R00N` + 可选 `AVG/`，见规范 §2 |

单位约束：距离 m、频率 Hz、原始样本 int16/LSB、功率谱线性幅值、损耗 dB。**换算只允许在规范指定位置各发生一次**；UI 只做显示变换（§6）。

## 2. 总体描述

### 2.1 产品定位

GM-IX 上位机是单路 OFDR 整机的操作与数据软件：把厂商三级链路（`qt_acq` → `ofdr` → `detect`）编排成一次可追溯的测量，呈现**距离域曲线 + 指标表**，并按数据规范持久化为可审计的组目录。

### 2.2 用户与角色

| 角色 | 关切 |
|---|---|
| 产线操作员 | 一键测量、看到曲线与指标、合格/异常提示 |
| 工艺/调试工程师 | 分析区间、校准、重复平均与精度、历史对比 |
| 算法工程师 | 离线重算、与厂商数值对照、参数敏感性 |
| 集成开发 | 数据格式、错误契约、导出接口 |

### 2.3 运行环境

- Windows 10/11 x64；千兆网口；设备固定 IP `192.168.5.20`（主机如 `192.168.5.55`）
- 无外触发，软件触发（`trigger=0`）为唯一方式
- 单机单 DUT；同一 `GMIX_DATA` 只允许一个编排进程提交

### 2.4 约束

| ID | 约束 | 来源 |
|---|---|---|
| CON-01 | 厂商三级库均为无源码二进制（`qt_acq`/`ofdr`/`detect`，含 MATLAB MCC 加密），只能经声明接口调用 | [QT][OFDR][DET][HRAS] |
| CON-02 | 厂商结果内存由库分配，用后必须 `*_result_free`，异常路径同样释放 | [OFDR][DET] |
| CON-03 | 原始帧为 int16 小端、4 通道交织、每帧 8 字节，`ch0=P/ch1=S/ch2=A`，`ch3` 忽略 | [QT][DATA] |
| CON-04 | 数据格式、公式与错误分类以数据规范 v1.0 为准，不得在 UI 层另立口径 | [DATA] |
| CON-05 | UI 以厂商界面为参考但不复刻；布局、选项卡划分自主设计 | [决策] |
| CON-06 | 一期只做最小功能集（4 个页面），其余分期 | [决策] |

### 2.5 假设

- AS-01 同一时刻只连接一台设备。[决策]
- AS-02 设备可在 50 MHz / 8 ms / 软件触发下稳定采集（g50 已实测）。[HRAS][DATA]
- AS-03 无硬件时可用夹层回放/合成数据完整跑通 UI 流程。[决策]
- AS-04 厂商库可重复初始化/释放（待验证）。[TBD]

## 3. 系统能力与用例

| ID | 用例 | 主流程 | 验收要点 |
|---|---|---|---|
| UC-01 | 连接与就绪 | 打开会话 → 读版本 → 自检 → 就绪态 | 失败给出分类错误与可读原因 |
| UC-02 | 单次测量 | 设参数 → 采集 → 处理 → 指标 → 曲线/指标表刷新 → 落盘 | 指标与曲线同批数据一致 |
| UC-03 | 重复平均 | 设平均次数 N → 连续采集 → 线性 ps 平均 → 单次 detect → AVG 落盘 | N>1 生成 `AVG/`，精度仅 AVG 填 |
| UC-04 | 循环测量 | 按间隔连续测量，可随时停止 | 停止后无残留 staging，帧序连续 |
| UC-05 | 分析区间调整 | 改 startM/endM → 重算区间指标 | 只有区间内峰参与总 RL |
| UC-06 | 校准 | 录入参数 → 校验 → 版本化保存 → 重算 | `calibrationId` 随结果落盘，configHash 失效规则生效 |
| UC-07 | 曲线查看与定位 | 缩放/平移 → 游标读数 → 点事件行定位 | 峰值标记落在曲线上，读数与数据一致 |
| UC-08 | 历史检索 | 选组 → 回读 → 曲线/指标/事件重现 | 与首次结果逐字段一致 |
| UC-09 | 导出 | 选组/本次 → 导出 CSV/报表 | 导出只读，不修改原始数据 |

## 6. 显示口径与符号规范（DS）

**原则（唯一口径，评审决议 2026-11-05）**：数据字段恒为规范定义（dB_rel 正刻度）；UI 显示统一为厂商负刻度；显示变换只在 UI 层单点实现，不写回任何数据字段。**§6 是 UI 显示的唯一口径**，其他章节、模块、导出与外部工具不得另立换算规则。

DS 条目是显示规则，不设优先级与来源列；来源统一为 `[图][决策]`，验收方法见各行。

| ID | 指标/元素 | 数据字段 | 显示规则 | 验收 |
|---|---|---|---|---|
| DS-01 | 曲线电平、游标、事件回损 | `heightDbRel` / `rlDbRel` | 显示值 = 字段 + `rlOffsetK`（≈ -192），负刻度 -150 ~ -40 | D |
| DS-02 | 总回波损耗 | `totalRlDb` / `totalRlRawDb` | 已标定显示 `totalRlDb`（负值）；未标定显示 `totalRlRawDb + 默认偏移` 并标"未标定"；显示带 `dB` 后缀 | D |
| DS-03 | 事件台阶 | `stepLossDb` | 正损耗，原样显示（列头已标 dB，数值不带后缀） | D |
| DS-04 | 总插入损耗 | `totalIlDb` / `totalIlRawDb` | **以正值显示**（与厂商 HRAS-9000 一致，如 12.13 dB）；该规则**只适用于 IL 域**，严禁对任何 RL 字段取负 | D |
| DS-05 | 插损/回损精度 | `ilPrecisionDb` / `rlPrecisionDb` | 恒为正，原样显示并带 `dB` 后缀；`null` 显示"—" | D |
| DS-06 | 未标定默认显示偏移 | — | 固定显示参数 -192（本机 g50 四峰拟合：+147→-45、+120→-72），仅用于未标定态；必须同屏常驻标注"未标定"；不得参与合格判定、不得作为测得值导出；标定后改用 `calibration.rlOffsetK` | D |
| DS-07 | 显示值持久化 | `view.json` `yRange`/`cursor` | 仅记录视图状态，不参与任何计算、判定与验收 | I |
| DS-08 | 显示变换实现位置 | — | 仅在 UI 呈现层执行，存储与处理层不得做显示变换 | I |

> DS-04 与 DS-01 的"符号"性质不同：DS-04 是**指标显示方向**（2026-11-06 按厂商 UI 实测裁定为正值，不再取负），DS-01 是**零点偏移**（相对电平 vs 绝对回损）。二者都不是取倒数（取倒数会翻转单调性，与厂商四峰斜率 ≈ +1 矛盾）。

## 12. 评审决议（2026-11-05）

原 §12 四项待评审事项已全部裁定，本版无遗留待评审项。

| # | 原待评审事项 | 裁定 | 理由 | 落地位置 |
|---|---|---|---|---|
| 1 | §6 显示口径是否作为 UI 唯一口径 | **采纳为唯一口径**（与规范 §7、§0.3 #12 一致） | 唯一口径是"任何层不得对 RL 取负"的唯一执行保障；允许第二口径必然诱发取负实现，退回取倒数错误 | §6 原则句、DS-04 限定 |
| 2 | DS-06 未标定默认偏移 -192 是否允许直接显示 | **允许，附三项硬约束**：同屏常驻标注"未标定"；不写数据字段（`view.json` 除外）；不参与判定、不作测得值导出 | -192 是本机 g50 四峰拟合的**显示锚点**，非标定值；标注与隔离可防操作员误当绝对 RL | DS-06 |
| 3 | NFR-PERF-02/03 数值是否按产线节拍调整 | **PERF-02 澄清**为"单帧渲染 ≤100 ms，不含采集/处理/落盘"；**PERF-03 保留 1 s** 但限定"本地 SSD + `saveRaw=always`"、降为不阻断验收的工程自检线；产线节拍另立需求 | 原"100 ms/帧"与端到端 150 ms 自相矛盾；N=5 合计 1 s 无实测样本，且强依赖磁盘类型 | §7 |
| 4 | 配置管理（AFE/Range/Functional/Interface）是否提前到 P0 | **拆分**：配置**快照只读加载 + `configHash` 计算**进 P0（新增 FR-CFG-01）；四类配置**编辑界面**留 P1 | P0 校准须绑定 `configHash`（FR-CAL-03/FR-MET-05），无 hash 无法验收；AS-02 已固定 50 MHz/8 ms 工作点，编辑界面非 P0 必需 | §4.10、§10、§11 |

后续变更纪律：新增需求按文首"文档规则"的编号与来源规则登记，并回填追溯矩阵；触及数据语义的变更须先在数据规范 §0.4 升版本，再同步本文件。
